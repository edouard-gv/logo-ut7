# Générateur SVG UT7

Page TypeScript autonome qui transforme une notation comme
`m1/-c1-0-c1-m1-12-m0/` en SVG paramétrique.

Le chiffre indique toujours le niveau inférieur de la barre : `c1` relie
les niveaux 1 et 2, tandis que `m1` relie les niveaux 1 et 3. Un `/`
incline la barre. Les liens sont tracés au niveau indiqué entre deux barres.

## Lancer le projet

```bash
npm install
npm run dev
```

Pour produire les fichiers statiques :

```bash
npm run build
```

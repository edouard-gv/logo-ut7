# Générateur SVG UT7

Page TypeScript autonome qui transforme une notation comme
`m1/,c1,1,c1,m1,12,e0.3,m0/` en SVG paramétrique.

Le chiffre indique toujours le niveau inférieur de la barre : `c1` relie
les niveaux 1 et 2, tandis que `m1` relie les niveaux 1 et 3. Un `/`
incline la barre. Les liens sont tracés au niveau indiqué entre deux barres.

Les éléments sont séparés par des virgules. Un élément `eX` modifie l’espace
vide de `X` fois l’espacement entre les barres. Par exemple, `c1,e1,c1` ajoute
une part supplémentaire (`e+1` est équivalent), tandis que `c1,e-1,c1` en retire une. Les valeurs
décimales utilisent un point (`e-0.5`).

L’option « Haut des barres horizontal » remplace la coupe supérieure
perpendiculaire des barres inclinées par une coupe horizontale.
L’option « Bas des barres horizontal » applique indépendamment le même
principe à la coupe inférieure.
Le curseur « Arrondis » règle le rayon appliqué à tous les coins du tracé
fusionné. Une valeur nulle conserve des angles vifs.

L’option « Inscrire dans un trapèze » remplace le fond rectangulaire par le
plus petit trapèze circonscrit. Ses côtés suivent les bords extérieurs de la
première et de la dernière barre ; ses bases sont orientées selon leur
bissectrice afin de rendre le trapèze symétrique. Les barres intermédiaires et
les liens sont ignorés pour le calcul de son enveloppe.

L’option « Fond transparent » retire l’aplat Margaux. L’option « Barres et
liens transparents » soustrait leur forme du fond. Ce fond reste crème dans
l’aperçu comme dans les fichiers SVG et PNG téléchargés.
Lorsque le fond est trapézoïdal et que l’arrondi vaut zéro, cette découpe est
une soustraction booléenne exportée dans un seul tracé, sans raccord de masque.
Dans ce mode, si un seul coin d’une petite extrémité de barre extérieure touche
une base du trapèze, la soustraction est prolongée jusqu’à cette base. Le petit
triangle résiduel est ainsi supprimé sans désactiver les coupes horizontales,
sauf lorsqu’il touche un lien horizontal.

Le bouton « Sauver la configuration » encode la notation et tous les réglages
dans un tableau JSON versionné et compact (les cases sont regroupées dans un
bitmask), puis en Base64 URL-safe. Il l’ajoute au paramètre GET `config`, met
l’adresse courante à jour sans rechargement et copie l’URL. Son ouverture
restaure automatiquement tous les contrôles.

Le SVG téléchargé reprend cette même configuration dans son nom, sous la
forme `ut7-<configuration>.svg`.

## Lancer le projet

```bash
npm install
npm run dev
```

Pour produire les fichiers statiques :

```bash
npm run build
```

Les fichiers sont générés dans `dist/`. À chaque push sur `main`, le workflow
GitHub Actions `.github/workflows/pages.yml` reconstruit ce répertoire et le
publie avec GitHub Pages. Dans les paramètres du dépôt, choisir **Pages**, puis
**GitHub Actions** comme source de déploiement.
